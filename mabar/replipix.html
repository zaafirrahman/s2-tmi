Replipix

Cara kerja & fungsi

Kodemu dijalankan sekali per sel dengan x dan y (y positif ke atas). return angka (0 atau negatif = kosong, di atas 16 berputar lagi: 17=WHITE, 18=GRAY, dst) atau konstanta warna: WHITE=1, GRAY, BLACK, PEACH, PINK, PURPLE=6, RED=7, ORANGE, YELLOW, LIME, GREEN, NAVY, BLUE, SKY, BROWN, MAROON=16. Tanpa return atau false = kosong, true = putih (1). Tersedia: if/elseif/else, variabel, for, operator aritmetika dan bitwise, serta min, max, abs, floor, round, ceil, step, sign, clamp, inrange, mix, sqrt, sin, cos, tan, asin, acos, atan, btoi, sort, insert (tanpa prefix math.). Code size = jumlah token (komentar tidak dihitung). Cycles = rata-rata instruksi VM per sel. Skor = size + cycles, makin kecil makin bagus.
