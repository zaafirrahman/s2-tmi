1 · Analisis multivariat & variate

  • Multivariate analysis: analisis simultan atas lebih dari dua variabel (Hair dkk., 1984; pustaka utama Hair dkk., 2010)
  • Variate = kombinasi linier variabel dengan bobot yang ditentukan secara empiris
Nilai variate = w1X1 + w2X2 + … + wnXn

Tujuan kuliah: konsep & praktik analisis data memakai statistika multivariat dan perancangan percobaan untuk penelitian empiris kuantitatif.

3 · Validitas, reliabilitas, error ukur

  • Validity: sejauh mana ukuran mewakili secara akurat apa yang seharusnya diukur
  • Reliability: sejauh mana variabel teramati mengukur nilai ‘sebenarnya’ dan bebas error
  • Setiap pengukuran tidak bebas kesalahan (penggaris vs jangka sorong; bagaimana mengukur kepuasan?). Error pengukuran memperbesar error model

5 · Memilih teknik yang tepat

3 pertimbangan:

  1. Jenis data (skala nominal/ordinal/interval/rasio)
  2. Desain penelitian: independensi sampel · jumlah kelompok objek/data · jumlah variabel
  3. Asumsi yang mendasari uji (pelanggaran → hasil tidak valid)
  • Uji pengaruh metode diet → uji-t
  • Rataan produktivitas 3 jenis pupuk → ANOVA
  • Pengaruh media, budget, lama ekspose, bintang iklan thd penjualan → multivariat

Asumsi contoh: uji-t → populasi normal; regresi → variansi y sama untuk semua x.

8 · Data & rumus matriks

Xij = nilai variabel ke-j pada case ke-i (n case, p variabel; matriks X berukuran n×p).

mean corrected: xi = Xi − X̄ ; Xd = X − 1x̄'
centroid: x̄' = (1/n) 1'X
sX = √(x'x / n)   (slide, rumus 1)
s² = xd'xd / (n−1)
cov CXY = x'y / n
rXY = x*'y* / n = x'y / (|x||y|) = cos θ
standar: Xs = XdD−1/2 (D diag. variansi)
ΣX = 1'X ; ΣX² = X'X ; ΣXY = X'Y
B = X'X (diag = sum of square, lainnya cross product)
S = X'X − (1/n)(X'1)(1'X) = Xd'Xd
C = S/(n−1) ; R = (1/(n−1)) D−1/2 S D−1/2

9 · Preprocessing data

3 objektif (Sekaran, 1992): getting the feel for the data · testing the goodness of data · testing hypothesis / menjawab pertanyaan penelitian

Feel for the data (statistik deskriptif & grafik: histogram, scatterplot, boxplot, wajah Chernoff). Waspadai:

  • statistik ekstrem → salah input
  • variabilitas respons sangat rendah → pertanyaan tak tepat / responden tak paham
  • respons cenderung sama → pertanyaan bias
  • korelasi antar variabel tak sesuai logika/teori

Hanya diagnostik awal; tidak menggantikan diagnostik statistikal.

10 · Missing value & outlier

Missing value — 3 opsi (pilih setelah cek: apakah missing bersifat random?):

  1. abaikan kuesioner (delete cases)
  2. ganti nilai (nilai tengah skala, rata-rata respons lain, atau teknik statistik)
  3. hapus variabel dengan banyak missing

Outlier 4 kelas: procedural error · extraordinary event dengan penjelasan · extraordinary event tanpa penjelasan · kombinasi unik tanpa kejadian luar biasa

Deteksi: univariat (normalisasi, batas 3) · bivariat (plot dua variabel) · multivariat (jarak Mahalanobis)

Jangan buru-buru dibuang (mengurangi generalizability); buang hanya jika benar-benar aberrant.

11 · Goodness of data

  • Validitas data: uji lewat confirmatory factor analysis & teknik uji validitas lain
  • Reliabilitas alat ukur: alpha Cronbach

Setelah itu: uji hipotesis dengan teknik yang tepat (jenis data, desain, asumsi).
