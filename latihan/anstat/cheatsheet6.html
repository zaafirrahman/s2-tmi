1 · Apa itu SEM?

  • Teknik dependen sebelumnya: satu hubungan pada satu waktu & error pengukuran = 0
  • SEM: menganalisis beberapa hubungan dependen sekaligus (simultan) → efisiensi statistika; juga memodelkan variabel dengan error pengukuran

2 karakteristik dasar:

  1. estimasi banyak hubungan dependen yang saling terkait
  2. mampu merepresentasikan konsep tak teramati (variabel laten) & memperhitungkan measurement error

Contoh sistem persamaan: Y1 = X1 + X2; Y2 = X1 + X3; Y3 = Y1 + Y2.

2 · Variabel laten & error pengukuran

  • Laten: tak diamati langsung (mis. kepuasan, loyalitas); manifes / indikator: teramati (butir kuesioner)
  • Reliability: sejauh mana variabel ‘bebas error’. Validitas ≠ reliabilitas
  • Measurement model: hubungan variabel laten → manifes; satu konsep bisa diwakili banyak pertanyaan (mis. summated scale)
βy|x = βs × ρxteramati = sebenarnya × reliabilitas prediktor → error pengukuran melemahkan koefisien
βs = 0,60; ρx = 0,80 → teramati = 0,48 (0,60/0,80 = 0,75 adalah koreksi, bukan nilai teramati).

4 · Persamaan struktural & compound path

Contoh: 3 attitude (job satisfaction, org. commitment, prob. turnover) dari 3 anteseden.

Job sat. = co. att. + work env.
Org. comm. = job sat. + pay level
Prob. turn. = job sat. + org. comm.

Var. endogen = β·var. eksogen + β·var. endogen + error, mis.
Y1 = β1X1 + β2X2 + e1; Y3 = β7Y1 + β8Y2 + e3

Korelasi = compound paths (X1→Y1 koef. B, X2→Y1 koef. C, X1↔X2 koef. A):

rx1,x2 = A
rx1,Y1 = B + AC
rx2,Y1 = C + AB
r = 0,5; 0,6; 0,7 → A = 0,5; B + 0,5C = 0,6; C + 0,5B = 0,7 → B = 0,33; C = 0,53

6 · Peran teori & strategi modeling

  • Hubungan sebab-akibat ditentukan oleh justifikasi teoretis, bukan hitungan. 4 kriteria kausal: asosiasi cukup · urutan waktu (sebab sebelum akibat) · tak ada variabel penyebab alternatif · dasar teori
  • Risiko: specification error, overfitting
StrategiCiri / kelemahan
Confirmatoryspesifikasi 1 model & uji (works or doesn’t). Kelemahan: confirmation bias; hanya satu dari beberapa model yang bisa diterima
Competing modelsbandingkan beberapa model, pilih yang paling kuat (contoh program TETRAD). Kelemahan: terlalu black box
Model developmentteori hanya titik awal; SEM eksploratori → respesifikasi. Jarang dipakai (SEM dibangun untuk konfirmatori)

7 · Langkah-langkah SEM

  1. Kembangkan model berbasis teori
  2. Bangun path diagram
  3. Konversi path diagram (measurement model, persamaan struktural, matriks korelasi hipotesis)
  4. Pilih tipe matriks input & tinjau masalah
  5. Nilai identifikasi, estimasi, goodness-of-fit, interpretasi
  6. Modifikasi model (respecification)

Respecification (tambah/kurangi parameter) hanya dalam kerangka teori; model baru divalidasi silang. Interpretasi: standardized vs unstandardized coefficients.

8 · Measurement vs structural model

KonstrukArah
Formativekonstruk dibangun oleh indikator (ada indicator loadings)
Reflectiveindikator = cerminan konstruk
  • Measurement model: variabel/indikator mana mengukur konstruk mana. Beda dengan analisis faktor: tiap indikator hanya dimuat pada konstruk yang ditetapkan (L1 pada A, L2 pada B, …)
  • Structural model: hubungan endogen ← eksogen/endogen
  • Isu penting: jumlah indikator per konstruk · reliabilitas · two step vs single step

9 · Input, sampel & estimasi

Asumsi input: observasi independen · random sampling · linier · normal (tidak menceng). Data lengkap (missing ditangani saat screening).

20 parameter × 10 = 200; × 5 = 100. 30 parameter, nonnormal: 15×30 = 450 > n = 150 (kurang).

Estimasi: maximum likelihood (minimalkan selisih matriks kovarians sampel dan matriks kovarians implikasi model Σ(θ)). Proses: direct estimation · bootstrapping · simulation · jackknifing.

11 · Goodness-of-fit & offending estimates

Offending estimates (perbaiki dulu): variansi error negatif · standardized coefficient ≥ atau sangat dekat 1 · standard error sangat besar.

Ukuran fitCiri
Absolutefit keseluruhan; tanpa penyesuaian overfitting
Incrementalbandingkan dengan model lain buatan peneliti
Parsimonioussesuaikan dengan jumlah koefisien
  • Measurement model fit → reliabilitas indikator (mis. Cronbach’s alpha)
  • Structural model fit → signifikansi koefisien yang diestimasi
α = 0,87; 0,82; 0,84 (ukur baik); hanya 2 dari 5 koefisien struktural signifikan → struktural belum seluruhnya didukung.

12 · Jika–maka (cepat)

  • Konstruk laten + banyak indikator + hubungan antar konstruk → SEM
  • Tidak ada panah masuk → eksogen; ada panah masuk → endogen
  • df > 0 → over-identified (diinginkan); = 0 → just; < 0 → under
  • Data jauh dari normal → rasio sampel naik ke 15:1
  • Teori kuat sebagai dasar kausal; ubah model hanya dengan alasan teori + validasi silang
