1 · Tujuan & ide dasar

  • 2 tujuan: (1) mengidentifikasi konstruksi yang mendasari data; (2) mengurangi jumlah variabel agar mudah ditangani
  • Proses mentransformasi variabel orisinal → variabel baru (faktor) yang saling tidak berkorelasi
  • Faktor = kombinasi linier variabel orisinal (atau sebaliknya)
  • Faktor diurutkan variansi terjelaskan menurun: F1 paling informatif, faktor terakhir paling sedikit
  • Jumlah faktor maksimum = jumlah variabel awal (p); umumnya diambil sejumlah kecil yang dinilai mencukupi
2 variabel (12 responden): var X1 12,17 + var X2 13,23 = 25,40 = var F1 25,31 + var F2 0,09. Total variansi tetap, tapi F1 membawa hampir semuanya → cukup 1 dimensi.

2 · PCA vs common factor

PCA : PCm = wm1X1 + wm2X2 + … + wmpXp
CFA : Xp = vp1CF1 + … + vpmCFm + ep
  • PCA: komponen = kombinasi variabel, tanpa suku error
  • CFA: variabel dijelaskan faktor umum + error unik e

3 · Syarat input & kecukupan data

  • Variabel awal punya landasan teoritis/logis
  • Sejauh mungkin metrik
  • Magnitude (skala) seragam; jika tidak, standardisasi atau pakai matriks korelasi sebagai input

KMO (kecukupan sampel keseluruhan):

0,90marvelous0,60mediocre
0,80meritorious0,50miserable
0,70middling<0,50unacceptable

Diagonal matriks korelasi anti-image = kecukupan tiap variabel. Jika < 0,50 → penyertaan variabel perlu dipertimbangkan kembali.

KMO 0,74 antara 0,70 dan 0,80 → middling.

5 · Bobot faktor & komunalitas

Komunalitas h² = Σ (bobot)² pada faktor yang dipertahankankuadratkan dulu, baru jumlahkan (bukan jumlah bobot)

Komunalitas = proporsi variansi variabel yang dijelaskan faktor-faktor yang diekstraksi.

X1: (−0,30)² + 0,85² = 0,09 + 0,7225 = 0,81. Bobot 0,6 & 0,8: 0,36 + 0,64 = 1,00. X5 komunalitas 0,96 → 96% variansinya terwakili.

6 · Rotasi faktor

  • Orthogonal (mis. Varimax): sumbu tetap tegak lurus 90° → faktor tetap tak berkorelasi
  • Oblique: sumbu boleh membentuk sudut lain (mis. 85°) → faktor boleh berkorelasi
  • Tujuan rotasi: tiap variabel jelas masuk ke satu faktor

7 · Langkah membaca output (contoh 5 variabel)

  1. Matriks korelasi: cari kelompok korelasi tinggi. X4–X5 = 0,927; X3–X4 = −0,832; X3–X5 = −0,774 (tanda − = arah berlawanan, bukan lemah); X1–X2 = 0,610; X1–X4 = −0,018 → 2 kelompok
  2. Cek KMO & anti-image
  3. Tentukan jumlah faktor (eigen, % variansi, scree)
  4. Rotasi (Varimax)
  5. Kelompokkan variabel ke faktor dengan bobot terbesar; beri nama
  6. Cek komunalitas

8 · Skor faktor & validasi

  • Skor faktor = kombinasi linier variabel standar dengan koefisien skor faktor
Skor F1 = −0,039X1 + 0,089X2 − 0,315X3 + 0,359X4 + 0,359X5
  • Skor faktor dipakai sebagai input analisis lanjut (cluster, diskriminan, regresi berganda); variabel awal direduksi → hitungan lebih mudah
  • Validasi = replicability: bagi data jadi dua (atau pakai data lain terpisah), ulangi analisis, bandingkan dengan hasil awal
