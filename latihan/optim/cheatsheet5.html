1 · Pembatas persamaan: Lagrange

Opt f(x), x ∈ Rn, dengan m pembatas gi(x)=0 (f dapat diturunkan 2×, gi dapat diturunkan)

L(x,λ) = f(x) − Σi=1..m λigi(x)λ = pengali Lagrange (m buah)

Kondisi perlu: ∂L/∂xj=0 (j=1..n) dan ∂L/∂λi=−gi(x)=0 (i=1..m) → n+m persamaan untuk n+m variabel (x,λ)

Jika ditulis L=f+λg: x* tetap, hanya tanda λ berbalik.

2 · Contoh Lagrange

Slide: min x1²+x2²−2x1−2x2, x1+x2=1

2x1−2−λ=0; 2x2−2−λ=0; x1+x2=1 → x*=(½,½), λ=−1, f=−3/2

maks x1x2, x1+x2=10: x2−λ=0, x1−λ=0 → x1=x2=λ=5, f=25

min x1²+x2², 2x1+x2=5: x1=λ, x2=λ/2 → λ=2, x*=(2,1), f=5

maks x1+x2, x1²+x2²=2: x1=x2=1/(2λ), λ=±½ → (1,1) dan (−1,−1): dua titik stasioner, bedakan lewat kondisi cukup

4 variabel + 2 pembatas → 4+2 = 6 persamaan, 6 variabel.

3 · Hessian bordered

  • Ukuran (m+n)×(m+n); evaluasi di (x*,λ*)
  • P: ∂gi/∂xj (m×n); Q = Hessian L terhadap x (n×n)
  • n=4, m=2 → 6×6, P 2×4, Q 4×4

6 · Pembatas pertidaksamaan: KKT

Model: opt f(x) dengan gi(x) ≤ 0, i=1..m. L = f − Σλigi.

Bentuk standar: 2x1−x2≥4 → −2x1+x2+4 ≤ 0 (ruas ke kiri, kalikan −1 → tanda berbalik)

Syarat KKTbentuk
tanda λλi≥0 (maks); λi≤0 (min)
stasioner∂L/∂xj=0, j=1..n
complementary slacknessλigi(x)=0
kelayakangi(x)≤0

Aktif: gi=0; tak aktif (gi<0) → λi=0. Jumlah syarat = m+n+m+m: n=3,m=4 → 15; slide n=2,m=3 → 11

7 · Prosedur kasus KKT

  1. Bagi 2m kasus: tiap λi=0 atau ≠0 (m=4 → 16; m=3 → 8)
  2. λi≠0 → gi=0 (aktif); λi=0 → abaikan gi
  3. Pecahkan x, λ dari stasioner + pembatas aktif
  4. Cek layak (semua g≤0) dan tanda λ
  5. Lolos keduanya = memenuhi kondisi perlu
