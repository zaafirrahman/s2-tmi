2 · Ketetanggaan & solusi layak

N(x) = { y : ‖y − x‖ < ε }ε>0 sangat kecil; y tetangga x jika jaraknya < ε (tepat di batas = bukan)

x=(1,1), ε=0,5: (1,3; 1,3) jarak 0,424 → tetangga; (1,4; 1,4) jarak 0,566 → bukan

  • Layak: x ∈ S (memenuhi himpunan pembatas); tak layak: x ∉ S. Himpunan solusi = semua solusi layak

S: 5x1+3x2≤15, −x1+x2≤1, x2≤3, x≥0. (1,5; 2,5): 15≤15, 1≤1, 2,5≤3 → layak. (2,2): 16>15 → tak layak

4 · Uji kecembungan dengan turunan

1 variabel: f″(x) > 0 untuk semua x → cembung; f″(x) < 0 untuk semua x → cekung; f″ berubah tanda → tak cembung & tak cekung

ff″hasil
x²+2x+32cembung
−x²−2x+3−2cekung
x³+3x²6x+6tak cembung, tak cekung (ganti tanda di x=−1)

Multi variabel: gradien ∇f = (∂f/∂xj); Hessian H(x) = [∂²f/∂xi∂xj] (n×n)

  • H definit/semidefinit positif untuk semua x ∈ S → f cembung
  • H definit/semidefinit negatif → f cekung
  • H tak definit → tak cembung & tak cekung

† Pelengkap dari pembahasan soal: H definit (tanpa nilai 0) → sempurna; semidefinit (ada 0) → cembung/cekung tapi tak sempurna, mis. (x1−x2)² (LPM 2 dan 0).

6 · Solusi optimal: global & lokal

  • Optimal global x*: f(x*) ≥ f(x) (maks) / ≤ (min) untuk semua x ∈ S
  • Unik: ketidaksamaan ketat (> / <), satu-satunya
  • Optimal lokal: hanya untuk x ∈ N(x*) (ketetanggaan)
  • Global ⇒ lokal (†); lokal belum tentu global

Slide: maks f(x)=x⁵/5−35x⁴+(6625/3)x³−60375x²+675000x, 0≤x≤63: x=10 lokal, x=45 global.

7 · Transformasi model

maks Z=f(x), x∈S  ≡  min Z′=−f(x), x∈SZ = −Z′; x* sama

maks Z=−x²+4x+7 → min Z′=x²−4x−7: x=2, Z′=4−8−7=−11 → Z=11

Konstanta pada f(x)+c tidak mengubah x*; hanya menggeser nilai Z (Z=Z′+c)

min (x−3)²+100, x≤2: tanpa batas x=3 (tak layak) → x*=2, Z=1+100=101

9 · Pemrograman linier (LP)

  • Ciri LP: variabel majemuk & kontinu; berpembatas; f & pembatas linier; tujuan tunggal; parameter deterministik (bukan stokastik)
  • LP = kasus khusus model cembung (S polyhedral, f linier). Ada solusi layak → dijamin ada optimal global

maks Z=3x1+2x2; 5x1+3x2≤15; −x1+x2≤1; x2≤3; x≥0. Optimum = perpotongan 5x1+3x2=15 & −x1+x2=1 → (1½, 2½), Z=9½, unik

† Cek titik sudut: (0,0)→0, (3,0)→9, (1,5;2,5)→9,5, (0,1)→2. Untuk Z=4x1+x2 optimum di (3,0), Z=12.
