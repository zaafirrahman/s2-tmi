TI5001 / Optimisasi & Intelejensia Komputasional · Pemecahan Analitik Model Optimisasi Tak-Linier Tak-Berpembatas

Latihan soal Unduh PDF

1 · Model & kondisi perlu

  • x ∈ Rn kontinu, bebas (−∞ < xj < ∞); f kontinu & dapat diturunkan 2×
  • Gradien ∇f(x) = (∂f/∂x1, …, ∂f/∂xn)T
∇f(x) = 0kondisi PERLU optimal → titik stasioner (n persamaan simultan, n variabel). Belum cukup!

Hessian H(x) = [∂²f/∂xi∂xj] (n×n). Evaluasi di titik stasioner x*: H(x*)

2 · Kondisi cukup (multi variabel)

Hitung det leading principal minor (LPM) H(x*) orde 1…n:

H(x*)x* adalah
definit positif atau semidefinit positifminimum lokal
definit negatif atau semidefinit negatifmaksimum lokal
tak definittitik belok (pelana)

Pola tanda LPM: definit + = (+,+,…); definit − = (−,+,−,…); selain itu (mis. +,−) = tak definit.

Parameter k: H=2kk2, LPM 2 dan 4−k² > 0 ⇒ −2 < k < 2 agar definit positif; |k|>2 tak definit

3 · Optimal global

  • Misal x* memenuhi kondisi cukup lokal:
  • f cembung (H definit/semidef. + untuk semua x) → x* minimum global
  • f cekung (H definit/semidef. − untuk semua x) → x* maksimum global
  • H berubah tanda menurut x → hanya lokal

x1⁴+x2²: H=diag(12x1², 2), LPM 12x1²≥0, 24x1²≥0 → semidef. + untuk semua x → cembung → (0,0) minimum global

Konstanta: f+c tak mengubah ∇f, H, maupun x*; nilai f di x* naik c (−x1²−x2²−2x1−2x2: maks 2; +10 → 12)

4 · Langkah pemecahan

  1. Hitung ∇f(x)
  2. Pecahkan ∇f = 0 → semua titik stasioner
  3. Hitung H(x); evaluasi di tiap x*
  4. Tanda LPM H(x*) → min / maks lokal / belok
  5. Cek H(x) untuk semua x → cembung/cekung → global

Kondisi perlu = ∇f=0; kondisi cukup = H(x*); global = bentuk f. Contoh sistem: 2x1−4+x2=0, 2x2+2+x1=0 → selesaikan simultan.

6 · Variabel tunggal

f′(x) = 0 → x* stasionerkondisi cukup di x*:
f″(x*)hasil
< 0maksimum lokal
> 0minimum lokal
= 0periksa turunan lebih tinggi

Global: f″>0 untuk semua x (cembung) → min global; f″<0 semua x (cekung) → maks global

7 · Turunan orde lebih tinggi

Jika f″(x*)=0, cari turunan ke-n pertama yang ≠ 0 di x*:

Turunan ke-ntandahasil
n genap< 0maks lokal
n genap> 0min lokal
n ganjil≠ 0titik belok
= 0lanjut n+1

f=x⁴/4 − x³/3: f′=x³−x²=x²(x−1) → x=0,1; f″=3x²−2x

  • x=1: f″=1>0 → min lokal
  • x=0: f″=0; f″′=6x−2=−2≠0 (ke-3, ganjil) → belok

−x⁶: turunan ke-6 = −720 < 0 → maks lokal. x⁵: turunan ke-5 = 120 (ganjil) → belok.
