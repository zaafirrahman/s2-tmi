2 · Cyclic coordinate: prinsip

  • n arah pencarian = vektor satuan sumbu: dj = 1 di baris j, 0 lainnya. Untuk n=3: d2=(0,1,0)T
  • y(1)=x(k) (awal iterasi k)
y(j+1) = y(j) + λjdjλj = opt f(y(j)+λjdj), fungsi satu variabel f(λj) → metode single (Materi 6)
  • Satu iterasi k: sumbu j=1..n berurutan; x(k+1)=y(n+1) (n=3 → y(4))
  • Pencarian satu variabel setelah K iterasi = n·K (n=2, 3 iterasi → 6)
  • λj boleh negatif

3 · Cyclic coordinate: langkah

  1. Langkah 0: ε>0, d1…dn, x(1), y(1)=x(1), k=1, j=1
  2. Langkah 1: cari λj; y(j+1)=y(j)+λjdj. j<n → j=j+1, ulang; j=n → langkah 2
  3. Langkah 2: x(k+1)=y(n+1). Jika ‖x(k+1)−x(k)‖ < ε berhenti; else y(1)=x(k+1), j=1, k=k+1, ke langkah 1

‖v‖ = √(v1²+v2²). Tidak memakai gradien.

5 · Gradient search: prinsip & langkah

  • Gradien ∇f(x) = (∂f/∂xj) ; arah penurunan tercepat = −∇f (min) → steepest descent; maks: +∇f → steepest ascent †
d(k) = −∇f(x(k)) / ‖∇f(x(k))‖(atau −∇f tanpa normalisasi). Satuan: panjang d = 1
x(k+1) = x(k) + λ(k)d(k) , λ>0λ(k) = opt f(x(k)+λd(k)) (satu variabel)
  1. 0: ε>0, x(1), k=1
  2. 1: jika ‖∇f(x(k))‖ < ε berhenti; else hitung d(k)
  3. 2: cari λ
  4. 3: x(k+1), k=k+1, ke 1
